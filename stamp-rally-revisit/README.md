# 旅のつづきミッション

観光スタンプラリー利用者の再訪を促す、旅行者向けWebアプリのMVPです。認証機能と管理者機能は含みません。

## 起動

Node.js 20以上が必要です。外部パッケージのインストールは不要です。

```powershell
cd C:\AI-Sprint\workspace\MC-000\stamp-rally-revisit
npm start
```

ブラウザで次を開きます。

```text
http://localhost:3000/revisit/
```

運営管理画面:

```text
http://localhost:3000/revisit/admin/
```

ポートを変更する場合:

```powershell
$env:PORT=3100
npm start
```

## テスト

```powershell
npm test
```

## 主な機能

- 行動・アンケート・未受取特典を使ったルールベース推薦
- テーマ別の再訪ミッション選択
- 訪問予定日の保存
- スポットのアクセス、所要時間、休憩場所、周辺情報
- ミッション進捗とバッジ記録
- 特典の未解放、解放済み未受取、受取済み表示
- 3種類のサンプル旅行者切替
- `localStorage` によるブラウザ内保存

## 運営管理機能

- 登録、スタンプ、一巡、2周目、特典受取のKPI
- 日別アクティビティと参加ファネル
- 再訪につながる対象者セグメント
- ログに基づく企画提案
- 対象者、ミッション、期間、チャネルを組み合わせた施策作成
- 施策の下書き、公開予約、アプリ内公開状態
- 利用者画面に表示される内容のプレビュー

管理画面から外部への通知送信は行いません。LINEは施策計画上のチャネルとしてのみ選択できます。

画面上の訪問記録は、既存スタンプ機能との連携を想定したデモ操作です。
